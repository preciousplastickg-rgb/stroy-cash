# Касса стройки

Учёт денег строительной компании: расходы, поступления, переводы, объекты, долги, отчёты.
Работает без интернета, все данные хранятся только на телефоне. Сервера нет.

## Установка

Откройте адрес приложения на телефоне:

- iPhone: Safari → «Поделиться» → «На экран Домой».
- Android: Chrome → меню → «Установить приложение».

Удаление иконки удаляет данные. Перед этим сделайте бэкап: «Ещё» → «Сделать быстрый бэкап».
